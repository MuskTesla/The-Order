# The Order 1.0.1

这次更新集中改进导入识别和日常书架操作。

**[下载 Windows 安装包 Setup.exe](https://github.com/Ph-Rank/The-Order/releases/download/v1.0.1/The-Order-1.0.1-Setup-x64.exe)**

## 更新内容

- 忘记配置 API 就导入了游戏：现在保存 API 后会继续批量识别未关联的本地作品，无需逐个重新操作。首次使用时，首页提供获取 API 和打开设置的提醒。
- 待核对列表确认或手动关联成功后，自动进入下一项；全部处理完返回书架。
- 修复识别排队统计遗漏外层等待任务的问题。资料复核、写入和图片准备完成后才计为已处理；书架首页直接显示进度、当前阶段和取消入口。
- 候选列表滚动到上下边界后，继续滚动可交给外层页面。
- 增加单项和批量“从书架移除”，支持右键、详情菜单和书架选择模式。移除只清理对应书架资料，不删除游戏文件。
- “继续游玩”改为小封面和右侧文字、按钮，不再把竖版封面放大成模糊横幅。
- 桌面及开始菜单图标随系统主题使用深色背景白图标、浅色背景黑图标。安装、启动及程序运行时同步；程序完全退出期间不额外常驻，下次启动再同步。
- 交互卸载时可选择保留或删除使用数据，默认保留；静默卸载保留数据。不会删除游戏文件。

## 安装与升级

Windows 11 x64（最低系统版本 22000），运行依赖随包提供。安装前请从系统托盘退出所有 The Order 实例，再运行 Setup.exe；覆盖升级保留现有书架、设置和游玩记录，无需先卸载。

首次使用请在 [NextMoe 开发者平台](https://developer.nextmoe.dev/) 获取 API 密钥，在设置中保存。识别有歧义或版本冲突时仍需人工核对。
