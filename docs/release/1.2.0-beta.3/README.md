# The Order 1.2.0-beta.3


正式版与 Beta 共用「The Order」入口及安装身份，默认程序目录 `%LOCALAPPDATA%\Programs\The Order`。
在「设置 → 程序更新 → 更新通道」选择正式版或 Beta，检查更新后点击安装；跨通道另有确认。
正式版默认只接收正式发行；选择 Beta 是明确参与测试，不会自动下载安装。

## 继续使用书架

切换程序版本继续使用当前物理 Profile，不复制或合并书架，不要求重新扫描游戏。
已有正式版使用 `%LOCALAPPDATA%\TheOrder\Profiles\Production`。
旧 beta.1 用户手动安装一次 beta.3；首次打开选择继续使用旧 Beta 书架后，沿用 `%LOCALAPPDATA%\TheOrder-Beta\Profiles\Beta`。
两份书架都存在时请仔细选择；取消会退出而不打开或合并资料。选择写入安装目录 `active-profile.json`，含身份编号，不能手填任意路径。
从旧 beta.1 无法在软件内自动更新，因为旧二进制没有这项能力；此一次过渡后，beta.3 与正式版1.1.1支持软件内切换。
安装前先从所有相关版本的托盘正常退出；不要在两个旧入口同时打开同一份书架。

## 备份与回退

软件内安装由原进程完成保存、释放资料锁并退出后开始。安装器执行前创建全量用户资料快照，位置为当前 Profile 的 `channel-backups/<本次编号>/data`；`snapshot.json` 为校验清单。
包含主库、个人设置、人工跨站确认、出版映射及加密凭据等用户伴随资料；可重建远程缓存、下载缓存、日志和既有快照不重复备份。
超过2 GiB/8192文件、文件被占用、链接路径或写入失败时中止安装，不能跳过备份继续。
快照可能含私密资料和加密凭据，不要公开上传；游戏本体与存档目录不在此快照中。

回退在设置中选择「正式版」，检查后点「回到正式版」。最低兼容正式版为1.1.1，不允许回到不支持新字段的1.1.0。
回退保留当前数据，不恢复旧快照，因此不会丢弃 Beta 期间新增的个人记录。
正式版不提供 Beta 的全部跨媒体、人工时长、攻略或辅助启动界面；对应数据保留。含扩展资料的旧式合并及资料混合刷新会拒绝，需回到 Beta 处理。
若安装被断电或外部终止，请重新运行选定版本完整 Setup 修复程序。未承诺所有中断后自动修复二进制；Profile 不由安装器迁移。
快照仅可在原物理 Profile 根、程序完全退出时恢复；不要把物理绑定 Profile 随意拷到新目录，也不要单独复制凭据。

卸载新「The Order」只移除程序及安装目录中的书架选择，保留两种命名空间里的书架、设置及备份。重装后可能需重新选择旧 Beta 书架。
旧「The Order Beta」入口可正常卸载，其旧卸载器保留资料；先确认统一入口已使用正确书架，勿手动删除 TheOrder-Beta 资料目录。
