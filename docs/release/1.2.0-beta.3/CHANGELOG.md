# The Order 1.2.0-beta.3

## 本次修复

- 修复资料语言首选中文时，资料源已提供中文译文却回退到日文的问题。资料源标记为机器翻译的既有译文现在也参与语言选择；有同语言的非机器译文时优先采用。
- 简介直接显示所选译文，取消额外的全文原文对照；「资料语言与来源」只说明当前字段的来源及语言。资料源机器译文保留简洁标记。
- 修复已缓存资料的显示选择，无需清空缓存、重新导入或迁移书架。显示译名不改变作品身份、人工对应关系或个人名称。
- 版本更新为 1.2.0-beta.3，可从 beta.2 在软件内检查更新；继续支持在设置中切回兼容正式版 1.1.1。

本轮不调用新的翻译服务，不安装本地翻译模型；资料源没有目标语言时按既有回退偏好显示可用资料。

## 更新内容

- 正式版与 Beta 可在设置内互相切换，共用程序入口和当前书架。
- 安装前保存并备份用户资料；校验来源、SHA-256、版本及跨通道兼容契约。
- 兼容读取与保存 Beta 用户字段，避免回退丢失个人记录与启动配置；不安全的旧式合并会明确拒绝。
- 旧 beta.1 一次手动过渡，可继续原 Beta 书架，不自动合并不同书架。
- 卸载保留资料；已发布旧版本附件不覆盖。

## 继续保留的 ACGN 能力

- Galgame：保留 NextMoe 作品、人物、Staff、发行资料及本地启动与游玩管理。
- 动画：Bangumi 关系与中文资料、AniList 角色/声优/Staff、逐集资料、PV 和正版平台入口。观看映射合并公开 bangumi-data；链接存在不等于当前可播放。
- 音乐：MusicBrainz 专辑、独立发行版本、多碟曲目、Recording/Work 与制作人员导航；常见曲名结合更多上下文生成候选。
- 漫画/轻小说：AniList/Bangumi 书籍资料、系列与卷册关系、NDL 独立出版记录、ISBN、作者/插画师及版本核对。不同层级不能仅凭同名自动合并。
- 多语言资料偏好与回退，直接使用资料源已有译文并保留来源；没有新增在线翻译服务或本地翻译模型。
- 人工跨站确认/排除独立持久化，远程缓存清理不会消除选择。
- 改善书籍、音乐、分集等页面层次、窄窗重排、链接命中、返回、缓存失败恢复及长路径原子写入。
- 全局启动辅助默认关闭；每个游戏可继承或覆盖 LE、Magpie、后台静音配置。


## 已知限制

详见 README 与 ROLLBACK。Beta 保留原有功能边界：未实现漫画逐章目录、VGMdb、MangaDex/MangaUpdates运行适配器或离线机器翻译。正式版仍为原Galgame功能集加通道与数据兼容修复。
