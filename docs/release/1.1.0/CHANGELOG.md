# The Order 1.1.0

本次更新加入匿名访问、NextMoe 账号登录、可选个人同步和软件内更新，并调整设置页。

## 主要更新

- **无需先填写 API**：首次使用默认匿名访问公开作品目录，导入即可识别；仍可登录 NextMoe 或使用已有 API Key。
- **NextMoe 账号登录**：通过系统浏览器授权，支持保持登录、重新登录与退出本机登录。
- **可选个人同步**：时长、状态、收藏夹可比较差异并逐项确认；评分只读并独立展示。所有同步默认关闭，登录不会自动上传记录，本地安装、笔记、评分和游玩历史保留。
- **软件内更新**：后台只检查，不自动下载；有新版时设置图标出现提示点，设置内展示主要改动，点击即可下载并升级。
- **减少更新下载和替换**：优先只下载变化块并校验完整安装包，安装时跳过内容相同的文件；不满足条件时回退完整包，支持跨版本升级。
- **Windows 10 兼容与设置整理**：兼容目标降低至 Windows 10 1809 x64，加入窗口与材质回退；设置统一左对齐，移除重复选项和多余说明。

## 个人同步范围

个人同步为可选功能，默认关闭。开启前先预览、核对并确认。

双向模式可自动导入安全的云端变化；本地时长和状态的后台上传需手动预览确认。服务端替换接口不支持条件更新，手动或单向上传期间请避免其他设备同时修改同一记录。冲突暂停，删除不自动传播；收藏夹额外权限另行授权。

真实匿名访问、账号登录、重启刷新、时长／状态／评分只读及退出闭环已验证；**真实个人数据写入／删除及收藏夹额外授权尚未完成验收**。对应逻辑已通过模拟与故障回归，使用前请核对预览。
