# 账号与凭据

各专业资料在来源允许时匿名访问；部分 NextMoe/Bangumi 能力需用户自行连接账号。
Beta 使用独立 Windows 本地资料和安全凭据存储，不读取或复制稳定版登录。不得把 Token 或 Profile 发到 Issues。
Bangumi Client Secret 保存在既有授权 Worker，客户端不包含 Secret；此 Beta 发布不部署或修改 Worker。

已有合成测试涵盖授权交换、保存、刷新、取消和并发；不将其等同于此最终 Beta 包的真实账号授权或等待真实 Token 到期联调。真实登录、到期续期及网络恢复请在愿意承担测试风险时参与验证。
