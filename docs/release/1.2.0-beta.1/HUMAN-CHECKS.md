# 公开测试建议

1. 空 Beta 书架导入自选目录，检查启动、计时、退出与重启；重要操作前导出备份。
2. 从 Galgame 连续浏览动画、音乐、漫画和小说，核对媒体、季度和发行版本；不确定身份先核对。
3. 展开分集、曲目、角色、出版资料，测试长标题、窄窗、滚轮、Tab、返回与主题。
4. 检查中文偏好与原文回退、缓存/断网提示和恢复重试。
5. 自行决定是否连接账号；不要公开任何授权材料。真实 PV、地区播放可用性依平台。
6. 报告 Windows 具体版本、DPI 与完整 Beta 版本。

正式版资格尚需：干净 Win10/11、实际 100%/150%/200% DPI、更多真实物理鼠标/键盘组合、OS 级断网及真实 OAuth 到期恢复、长期稳定性。自动化输入不等于物理验收。
