# 发布前人工验收清单

只有所有必要门禁完成后，才能决定公开发布。当前本机体验授权不等于公开发行授权。

| 操作 | 预期 | 失败时处理 |
| --- | --- | --- |
| 用空 Test Profile 在已准备好的干净 Windows VM 安装、重启、卸载 | 普通用户可用；卸载按选择保留资料，不改游戏文件 | 保留安装日志，停止发布；不要在日用宿主试验清理 |
| 在同一 VM 从当前公开 1.1.0 合成资料升级，再做程序与快照回退 | 个人数据与身份决定保留；旧程序遇新格式明确拒绝；恢复旧快照可重开 | 保留升级前后快照，勿在真实资料上试错 |
| 在实际 100%、150%、200% DPI 和可用窗口宽度连续浏览五类媒体 | 无重叠、关键按钮不截断、焦点顺序可用；回到原条目与位置 | 记录 DPI、尺寸、复现路径与截图；缩放窗口不等于更改 DPI |
| 鼠标／键盘操作 PV、观看入口、候选卡与跨媒体返回 | PV 内外滚轮手感自然；收起／离开停止播放；链接一次可触发 | 不反复授权或重复启动游戏，记录具体控件与操作 |
| 用用户实际安装的 LE／Magpie 配置继承、强制开关和恢复全局 | 全局初始关闭；工具缺失有提示；辅助工具不重复打开 | 先在合成安装和无害程序上重现，不对真实游戏强杀 |
| 自愿在隔离测试账号完成真实 Bangumi 连接、重启、刷新与断开 | 账号状态准确，失效可恢复，迟到响应不恢复旧账号 | 不发送 Token／Secret／授权码；仅提供脱敏状态 |

自动化中的本地 Worker、网络故障注入和原生 automation peer 必须分别标明，不能代替真实账号、真实断网或物理输入。签名、未来公开版本号及第三方许可中未确认的部分也需所有者最终核对。
