# 未发布候选变更

相对公开 1.1.0，本开发线加入并深化了 Galgame、动画、音乐、漫画和轻小说资料浏览；实际字段取决于数据源，不承诺每个作品都有全部资料。

- 集中管理 Locale Emulator、Magpie 路径和后台静音默认值；全局初始均为关闭，游戏支持三态覆盖与恢复跟随全局。
- 保留旧启动行为；新覆盖写入带版本的原生扩展。旧程序拒绝不认识的新格式，避免静默丢失配置。请先阅读 ROLLBACK.md。
- 修复后台退出游戏可能留下静音、管理器异常结束丢失恢复所有权、部分音频枚举失败被当空结果等问题。尊重用户的静音修改，单独调整音量不会阻止恢复。
- 动画支持按需分集、角色与声优、Staff、关系、官方 PV 播放器及观看入口。放送映射与 AniList 合并，保留地区、来源和版本；收录不等于当前版权可播放。
- 音乐支持有上下文的跨站检索、发行版切换、多碟曲目、录音／作品／音乐人深入导航。
- 书籍区分系列、单卷及独立出版记录；按明确身份和用户核对关联 ISBN，不把同名或不同层级视为同一实体。
- 人工跨站身份决定与远程缓存解耦；多语言内容以来源变体选择和回退，不覆盖原文或个人名称。
- 统一详情渐进加载、失败重试、原文展开、关键区块入口及返回路径；修复曾经的详情容器重叠和迟到分集结果抢回滚动位置。
- 分发包排除 PDB，并对自有程序集映射构建路径；保留独立的许可、依赖和文件哈希清单。

这是未发布开发线的范围说明，不表示已通过所有公开发行门禁，也不表示上述数据由 The Order 自建或获准重新分发全部封面和视频。
