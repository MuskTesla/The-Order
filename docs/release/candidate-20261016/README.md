# The Order 本机体验候选

这是基于当前未发布开发线的 Windows x64 候选，包含全局启动策略、ACGN 专业详情、跨站身份确认与资料语言偏好。公开正式发行基线仍是 GitHub 的 1.1.0；本包保留 1.1.0 产品版本，凭构建提交、候选目录和 SHA256 区分，尚未作为新版本发布。

全局设置中的「游戏启动与辅助工具」集中设置 LEProc.exe、Magpie.exe 和后台静音。三个全局开关首次均为关闭。新导入游戏跟随全局；旧安装保留原有效行为。游戏启动设置可分别选择跟随、开启、关闭，或全部恢复跟随全局。工作目录、存档位置、参数仍属于游戏安装。多个安装的原有工具路径分别保留，不擅自互相复制。

Locale Emulator 是启动代理；Magpie 在游戏启动后独立打开，缩放模式与快捷键仍在 Magpie 中设置。路径不可用或工具启动失败会显示提示。后台静音仅控制已确认游戏进程的音频会话，使用按需短命辅助进程保留静音恢复所有权，不安装服务、不注册自启动、不提升权限。管理器正常退出或异常结束后，辅助进程恢复仍由自己拥有的修改并退出。辅助进程自身被强杀、系统断电及独立音频子进程不在完整保证范围，异常提示出现时请检查游戏的系统音量。

ACGN 浏览从本地 Galgame 出发，经 Bangumi 关系进入动画、音乐和书籍。NextMoe 提供游戏专业资料，AniList 提供动画及漫画／小说资料，MusicBrainz 区分专辑组、发行版、录音和作品，NDL Search 补充可核对的出版记录。当前没有运行 MangaDex、MangaUpdates 或 VGMdb 适配器。漫画章节总数不等于逐章目录；没有上游目录时会明确说明。

选择中文资料偏好后优先使用已有中文，缺失时按备用语言、原文回退；保留来源和原始内容。本包没有安装翻译模型或调用在线机器翻译。人工确认、排除和撤销保存在独立用户组件，不随远程缓存清理而消失。

请完整保留应用目录。普通用户启动安装后的 The Order 即可，不需要 Node.js、.NET SDK、Bilibili 登录或元数据 API Key。在线资料和账号授权仍依赖网络及相应平台；范围见 AUTHENTICATION.md。包未签名；不要为运行它关闭系统防护。

完整隔离的干净 Windows 安装／升级／卸载／更新安装、其他系统与 DPI、真实鼠标手感仍有待验收；本机替换不代表这些门禁通过。发布前人工清单见 HUMAN-CHECKS.md，回退见 ROLLBACK.md。没有自动推送、公开发布或修改更新源。
