# 账号与网络范围

书架、安装、个人记录和人工身份决定以本地 Native Profile 为准。在线资料会向第三方发送请求，不能理解为软件完全离线或所有请求都只在本机处理。

| 用途 | 网络接收方与发送内容 |
| --- | --- |
| 游戏目录与图片 | NextMoe 目录请求、作品／人物／发行编号、搜索词；可匿名，登录为可选。封面也可能向注明的图片来源请求。 |
| 跨媒体关系与中文资料 | Bangumi 的作品、角色、分集及关系编号；连接后向 Bangumi 直接发送授权 Token 访问相应资料。 |
| Bangumi 快捷连接 | 浏览器访问 Bangumi 官方授权页；既有 Cloudflare Worker 处理授权码交换和刷新。客户端不内置 App Secret，不把普通元数据经 Worker 代理。 |
| 动画与漫画／小说资料 | AniList 公开 GraphQL，发送作品编号和检索条件，不要求用户申请 API Key。 |
| 音乐与封面 | MusicBrainz、Cover Art Archive 及注明的图片 CDN，发送专辑、发行版、录音、作品或人物编号。 |
| 出版记录 | NDL Search 的书名、ISBN 和目录编号，仅使用当前适配器允许的数据机构范围。 |
| 放送映射与程序更新 | GitHub 上的公开 JSON／发行元数据及必要下载。放送映射使用内置快照和低频更新；失败保留旧数据。 |
| PV 与外部观看 | 支持的 YouTube PV 展开后加载其官方播放器；Dailymotion 等不能嵌入的来源提供原站入口。观看链接由系统浏览器打开平台。相应平台会接收 IP、请求信息并执行地区、账号、年龄和版权限制。 |

账号凭据使用当前 Windows 用户安全存储。不要把 App Secret、Access Token、Refresh Token、授权码或带凭据的截图发给开发者。用户明确要求连接时才进入授权；断开连接、取消和失效恢复须沿应用已有流程处理。

资料或平台暂时不可用时，已保存的本地游戏资料仍可浏览。未命中不等于作品不存在；匿名 404 也可能与权限有关。观看平台条目存在不等于当前地区可播放。软件不下载、代理或重新分发视频，不提供漫画／小说资源下载或阅读器。

可选 NextMoe 个人同步按用户设置发送相应字段，不因浏览专业资料自动把整份本地库上传。缓存和人工决定分开；清缓存不会撤销手动决定。断开账号不等于删除已保存的本地书架。

第三方资料、图片和视频的权利分别处理，详见 THIRD_PARTY_NOTICES.md 和包内 NOTICE-Bangumi-Watch-Data.txt。AniList 对竞争性追番服务及数据囤积有明确限制；当前仅作 Galgame 中心的互补浏览，对未来公开扩张和缓存许可仍需复核。不能把 API 开放理解为所有内容都可自由再分发。
