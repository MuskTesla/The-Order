# The Order 1.0.0 · 首版发布说明

首个原生 Windows 版本提供简体中文本地 Galgame 书架、目录导入、多安装与启动管理、游玩计时、在线资料和发现搜索。

- 优先 KunGal 资料，核对作品及版本身份；识别不确定时保留旧关联并等待核对。
- 封面排除盘面、封底、原声带和其他不适合的用途，按构图及实际展示清晰度推荐；支持手动选择。
- 横幅采用独立的构图、留白和清晰度评分，横向铺满、保持原比例；支持本地横幅和恢复自动选择。
- 详情页使用无折射、低模糊玻璃信息框，保留系统保护与失败回退；横幅、玻璃和文字在就绪后同时出现。
- 记住已准备的推荐封面，重启直接恢复；图片准备、缓存和并发均有上限。
- 首次启动从已导入的安装目录中选择 exe 或 cmd；资料、安装设置、人员、角色、标签及相关作品采用统一的紧凑布局。
- 个人名称、分类、评分、笔记、安装、参数及游玩记录不被资料刷新覆盖。

支持 Windows 11 x64，最低系统版本 22000。仅启用简体中文；保留其他语言实现。正式包不带私人资料、缓存或游戏文件，不自动迁移旧 Electron 或 Test 书架。部分源图仍可能低清，未知或冲突的作品身份仍需人工核对。

本文件是准备好的发布文案；是否已经公开发布由发布记录决定。
