# 1.0.2 认证、同步、更新与 Windows 10 兼容候选

- 全新用户默认匿名访问公开目录，不携带认证头；旧版已保存的 API Key 保留，三种访问方式明确保存和切换。
- 加入 NextMoe 系统浏览器登录与安全环回回调，支持保持登录、串行刷新轮换、重新授权和退出本机登录。刷新失败或未知结果要求重新登录，不静默换成其他身份。
- 加入可选个人数据同步：时长、状态、收藏夹按类别选择方向，评分只读。全部默认关闭，先比较、预览、逐项选择，再明确确认。云端分钟数和评分独立保存，本地历史及小数评分不被覆盖。
- 收藏夹支持读取、独立成员映射、私密夹创建、导入愿望候选和逐项批量结果处理；移除与取消关联分别确认，不删除游戏文件。真实服务器游标用于增量读取，完整快照核对删除。
- 同步具有账号隔离、三方比较、作品编号复核、写入前持久化任务和同键重试；不确定任务保留恢复入口。自动同步仅处理已授权项目，冲突暂停。因官方替换接口无条件更新机制，双向后台上传改为提示用户预览确认，避免静默跨设备覆盖。
- 设置统一左对齐，保留首页的网格／列表切换，移除设置中的重复视图选项、材质生效说明、系统策略和不必要的小字。保留操作进度、错误、更新内容；必要权限和删除说明只在预览与确认时出现。

- 程序内更新优先使用差量下载：按 SHA-256 内容块比较新旧包，只请求缺失范围，合成后再次校验整个 Setup。支持跨版本直达，源缓存缺失、收益较低、Range 不可用或校验失败时只回退一次完整下载；用户取消不会触发回退。
- 安装包改为各文件独立压缩，减少小改动引起的连带变化；发布脚本生成同名 `.exe.blocks.json` 附件。安装器按每个文件的 SHA-256 跳过完整一致的程序文件，只新增／替换有变化的文件。安装／升级保留一份当前 Setup 字节作为比较缓存，普通卸载同时移除缓存；个人资料与安装交接规则不变。

- 启动后和使用期间自动检查公开正式发行；有新版时仅在设置图标右上角显示提示点，不弹窗、不自动下载，后台失败不打断使用。
- 设置加入“程序更新”：手动检查优先于后台检查，新版主要改动直接显示，完整说明可展开。点击“立即更新”即可下载、校验、保存退出、升级安装并重新打开，无需打开 GitHub 或提供额外密钥。支持下载进度、取消、网络失败重试，禁止降级及安装未完成／非本项目的附件。
- 下载按固定官方仓库、安装包名称、大小和 SHA-256 核对，保留 Windows 下载安全标记；安装交接同时要求保存完成的提交信号与原实例 PID／创建时间退出，退出取消、保存失败或崩溃时不安装。独立 Test／Development 只能检查更新，不能升级正式安装。书架与设置格式不变。
- 程序最低系统版本与安装器门槛统一为 Windows 10 1809 x64（17763）；保留新的 Windows SDK 引用用于编译，不再把引用 SDK 版本当作运行下限。
- 启用最低系统版本 API 检查，修复旧 Win10 不存在的动画变化通知订阅；1809 仍通过已有系统设置通知刷新动画与材质策略。
- Windows 10 使用主题色窗口背景，Mica 只在系统版本与控制器均支持时启用；Mica 附加失败后保持主题色回退，防止刷新时反复重试。横幅低模糊玻璃的策略独立保留。
- 依据能力启用自定义标题栏，失败时保留系统标题栏；旧系统不强制套用 Win11 的标题栏颜色策略。Win10 的等宽文字改用自带 Consolas；系统符号字体沿用 WinUI 的系统资源回退。
- 横幅文字检测使用原已随程序分发的固定 CPU ONNX Runtime，避免旧 Win10 内置 WinML 不支持 opset-15 模型。模型字节、归一化、文本排除规则及审美评分不变，不增加模型或执行提供程序下载。取消与释放会等待本地评估结束。
- 修复本地横幅已保存却无法进入缩略图缓存、显示空背景的问题；只允许固定本地横幅命名空间与 SHA-256，不放宽路径边界。原图与个人设置格式不变。
- 保留 1.0.1 的保存 API 后补识别、完整批次进度、连续核对、嵌套滚动、单项／批量移除、卸载资料选项、黑白系统主题图标和继续游玩小封面卡片。

候选未公开发布。真实 Win10 宿主不可用；验证范围以本轮报告为准，不能把模拟旧系统能力写成 Win10 实机通过。
