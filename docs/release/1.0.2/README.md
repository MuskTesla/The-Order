# The Order 1.0.2 本地候选

这是本地构建的兼容候选，尚未公开发布。面向 **Windows 10 1809 x64（内部版本 17763）及以上，以及 Windows 11 x64**。程序与运行依赖随安装包提供，用户无需安装 .NET SDK、Windows App SDK 或开发工具。

双击 `The-Order-1.0.2-Setup-x64.exe` 按中文向导安装。已有原生版可直接升级，升级保留书架、设置和游玩记录，无需先卸载；安装前从托盘正常退出程序。卸载默认保留使用数据，也可选择删除默认使用资料；游戏文件不删除。旧 Electron 或独立试用资料不会自动迁移。

首次使用默认匿名访问公开目录，无需账号或 API Key。导入后可自动识别，首页显示进度；有歧义的结果仍需核对。较大的游戏库可在设置中登录 NextMoe，以使用账号额度。旧版 API Key 保留，仍可在高级设置中保存、更换、移除和测试。

设置里的“登录 NextMoe”会打开系统浏览器。授权完成后返回应用；之后可保持登录、重新登录或退出本机登录。账号登录与个人数据同步相互独立，首次登录不会上传个人记录。

如需同步，在设置中选择时长、状态、收藏夹的方向，点击“预览差异”，逐项核对后“确认同步”。评分只从云端读取，并以独立来源展示；本地评分、安装路径、笔记和游玩历史保留。收藏夹使用独立成员列表，不覆盖本地分类或标签。检测到冲突时默认跳过，云端移除需另外确认；取消关联不会删除云端收藏夹或本地游戏。

开启自动同步后，仅处理已完成首次确认的项目。单向上传可提交稳定的新记录；双向模式的本地新记录需要预览确认，云端新增记录可自动导入。官方替换接口不支持条件更新，请在手动同步期间避免在其他设备修改相同记录。网络结果不确定时可用“恢复检查 / 重试”；过期或存在新冲突的旧任务可选择“核对并结束旧任务”，然后重新预览，不重复发送旧写入。详见 [认证、同步与隐私说明](AUTHENTICATION.md)。

启动后会在后台检查新版本，使用期间每 12 小时再检查一次。发现新版只在设置图标右上角显示提示点，不弹窗、不自动下载。进入设置可直接查看新版主要改动，完整更新说明可以展开；也可点击 **检查更新** 主动检查。

点击 **立即更新** 完成下载、校验、保存退出及安装，成功后重新打开。更新保留书架、设置和游玩记录；有未保存的编辑时先处理保存。检查无需 GitHub 登录或 NextMoe 密钥，不自动运行游戏。独立试用资料只能检查，不会通过更新替换正式安装。

更新优先比较新旧安装包的内容，只下载变化的部分，在本机合成新版并完整校验后交给安装器升级。安装时再核对程序文件内容，完整一致的文件跳过，只新增或替换有变化的文件。跨过多个版本也可以直接比较，不必逐版安装；首次升级、旧包缓存缺失、差量收益不大或下载服务不支持时，自动改用完整包。取消会停止整个更新，不会继续下载完整包。

安装目录保留一份当前安装包作为下次比较的缓存，大小约等于一个安装包；更新后替换，卸载时删除。该缓存不包含个人库或 API 密钥。发布时需要同时提供 Setup 和对应的 `.exe.blocks.json` 附件，缺少附件的旧发行仍可完整下载。差量优化减少下载量，实际安装仍沿用原安装器。

当前 GitHub 已公开的最新版本仍是 1.0.1，本地 1.0.2 候选会显示暂无更高的正式版本，不会降级。先安装包含此功能的版本，以后才可直接从软件中升级。安装包未签名，Windows 安全提示仍可能需要确认；更新功能不关闭或绕过系统防护。

Windows 10 使用随明暗主题变化的窗口背景；详情横幅的低模糊玻璃仍按系统效果设置与显卡能力启用。标题栏不能自定义时使用系统标题栏，窗口控制与应用内返回入口保留。封面、横幅、继续游玩卡片以及个人资料格式与 1.0.1 一致。

本轮完成自动化回归、原生 Test 界面流程、真实匿名请求和真人 OAuth 登录／重启刷新／私人接口只读／退出闭环。真实个人写入与收藏夹额外权限尚未验收，具体范围见候选附带的 `ACCEPTANCE.md`。**没有 Windows 10 实机或虚拟机，未进行真实 Windows 10 安装、文件选择器、显卡／显示缩放、长期使用验收。** 模拟回退和当前宿主启动不能替代该验收。安装包未签名，下载信誉提示仍可能出现；请保持系统防护开启。
