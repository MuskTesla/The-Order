# NextMoe 认证、同步与隐私

本文对应未公开发布的 The Order 1.0.2。默认本地独立使用；目录访问和个人同步分别控制。

## 访问方式

新用户默认匿名，仅请求公开只读目录，不发送 Authorization。匿名额度以服务响应为准；大批量识别可能需要等待。登录 NextMoe 可以使用账号额度。已有 API Key 用户保持原方式和 Windows 用户级加密文件；登录、退出或选择匿名不会清除旧密钥，只有“移除密钥”才移除它。

登录使用系统默认浏览器和 OAuth 授权码 + PKCE S256，不使用内嵌网页或应用密码。初次仅申请 openid、profile、catalog:read，不申请 email、preferences 或 catalog:edit。官方当前时长和状态接口只要求用户令牌，不需要额外 playtime 权限；收藏夹额外读取／写入权限仅在用户选择后说明并重新授权。公开 Client ID 是 2df77ee1e0167493048a94b677c73e10，没有 Client Secret 或内置开发者 API Key。

回调只监听系统分配端口的 127.0.0.1，固定 /callback，检查方法、Host、路径、随机 state、重复参数和可选 issuer。授权码只用一次，取消或五分钟超时关闭监听。访问令牌仅在进程内存；刷新令牌使用当前 Windows 用户 DPAPI，绑定已有 ProfileId 和 StoreId。

刷新串行执行，在请求前持久保存“轮换中”标记，成功后原子保存新令牌。未知服务器结果、进程中断或保存失败不会重新尝试旧刷新令牌，要求重新登录。认证切换取消旧身份请求，目录缓存、限流、同步与详情接纳均隔离；个人数据结果不能在切换账号后迟到显示。

“退出本机登录”清除本机令牌并回到匿名，保留书架、原 API Key 和各账号同步记录；不代表已经在服务器撤销授权。需要撤销服务器授权时，请在 NextMoe 账号端管理。登录文件损坏时，只有明确确认“重置本机登录”才覆盖该文件，书架和旧密钥保留。

## 同步语义

所有类别与自动同步默认关闭。预览只读，确认时按逐项选择提交。界面显示两侧数量、差异、冲突、进度和结果；暂停自动同步持久保存。首次账号登录、公开目录识别和书架移除都不授予个人数据提交权限。

时长为绝对累计分钟，本地为秒与真实会话。不会相加本地和云端汇总，不会虚构云端会话，不会删除本地历史。云端时长保存在独立账号来源，详情单独展示。只在云端基线未变、全部新增秒数能由基线后稳定结束的原生会话证明时追加，保留不足一分钟的秒数；无法证明或两侧变化时要求选择。不能向云端上传较小累计值；超过官方 60,000 分钟写入上限时保留并提示，不截断。

状态显式映射为未开始→wish、在玩→doing、已完成→done、搁置→on_hold、放弃→dropped。安装信息不参与转换，通关程度不推断。上传保留已有 completion；改为 wish 会清除它，需要单独明确选择。

收藏夹使用账号专属独立成员列表，可选择已有云端夹或确认创建私密夹，不对应安装路径、个人分类或标签。云端未安装作品需确认后加入愿望候选；云端删除不自动删除书架，本地移除不自动删除云端成员。映射与删除分别处理，默认不传播删除。旧收藏夹不可访问时显示冲突，可取消本机关联后重新选择。

评分只读取 NextMoe 的 1–10 整数，确认后保存并在详情标明来源；本地 0–10 小数评分完整保留，没有评分写接口调用。

写入前再次核对预览、当前账号、两侧基线和唯一目录编号，合并、歧义或已变编号要求重新关联。批量每次最多 100 项；207 逐项检查，失败不能算成功。POST 先原子记录 UUID 和完整受限请求，再发送；未知结果保留同键、同内容恢复任务，23 小时内可核对后重试。过期／两侧又变化时不重发，可读取现状后明确结束旧任务，再预览。

自动任务最多每五分钟检查一次云端变化；本地稳定新记录可提前触发。使用实际服务器 cursor，不构造游标；无游标或最多三十分钟后完整重读，收藏夹成员使用完整快照发现删除。只处理已有确认基线的作品及映射，不静默扩大到新导入作品或评分。

**当前限制：官方时长和状态替换写没有条件更新。** 客户端三方比较和提交前复核能发现已观察的冲突，不能使“读取→写入”跨设备成为原子操作。因此双向模式的后台本地上传留待手动预览确认，云端安全新增可自动导入；单向上传须由用户明确选择，期间避免其他设备同时编辑同一记录。严格并发无覆盖的全自动双向提交尚不成立，不将该限制标成已通过。

## 数据与网络边界

请求只向官方 account.nextmoe.com 认证端点和 api.nextmoe.dev 目录／个人 API 发出，不跟随 HTTP 重定向。图片、VNDB、Steam 和 GitHub 更新客户端不携带 NextMoe 令牌。请求有大小限制、取消和超时；共享调度读取 RateLimit、RateLimit-Policy、Retry-After，分钟限流等待，日额度耗尽停止，身份改变独立计数。

只提交作品编号、累计分钟、状态／通关程度及明确选择的收藏成员。安装目录、EXE、游戏本体、存档、笔记、私人文本、图片、缓存和凭据不上传；不加入站点编辑、偏好同步或云文件功能。读取本地程序线索沿用原边界，不运行游戏。

新增两个可选资料文件类别：native-nextmoe-auth.dpapi 与按账号／Client ID 区分的 native-nextmoe-sync-*.json，均绑定当前资料身份。同步文件 schema 2 还绑定当前 Windows 用户 SID，拒绝其他 Windows 用户／资料身份的内容；早期未发布的 schema 1 测试文件不自动套用新身份。旧库、密钥、备份格式不迁移或重写。书架导出不包含令牌或这些个人同步伴随文件；重装默认保留它们，卸载时选择删除默认使用资料才一并删除。自定义 Test 目录仍需单独管理。

自动化使用合成账号、临时原生资料和故障注入；真实匿名接口另行标注。用户已在隔离 Test 完成系统浏览器授权和目录连接，随后新进程刷新、时长／状态／评分只读访问、本机退出与退出后私人访问拒绝均通过，隔离书架字节未变。验收入口从程序层阻止个人写入；未请求收藏夹额外权限，本轮没有真实收藏夹读写、真实账号写入或删除验收。后续真实写入必须确认账号、作品、范围与预期结果，不能以模拟结果替代。
