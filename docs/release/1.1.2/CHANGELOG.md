# The Order 1.1.2

## 启动修复

- 修复从未安装旧 beta.1 的用户启动时报 `DirectoryNotFoundException`、无法打开书架的问题。旧 Beta 资料目录或其父目录不存在时，现在正常继续使用当前书架或创建新书架。
- 只放行尚未选择过的可选旧 Beta 资料不存在的情况；已选择书架丢失、身份不符、资料损坏、权限错误及链接目录仍安全拒绝，不自动改绑空书架。
- 旧 Beta 书架存在时仍由用户明确选择，不自动复制、合并或迁移。书架格式、账号凭据及已有个人记录不变。
- 正式版安装器同步修复过早访问尚未初始化的安装目录的问题；写入前仍检查所选目录的运行进程。

## 更新方式

程序可以打开时，在「设置 → 程序更新」检查当前通道更新。无法启动时，先从托盘正常退出仍运行的旧版，再下载本版本完整 Setup，安装到原程序目录；不需要删除、清空或重新导入书架。

正式版 1.1.2 与 Beta 1.2.0-beta.4 继续共享安装入口及所选物理书架；正式通道不会自动选择 Beta。旧发行附件保持不变。

## 功能范围与限制

正式版保持原有 Galgame 功能范围，只加入对应启动与安装修复；不将 Beta ACGN 功能混入稳定通道。

安装包未签名。Windows 10 实机、干净系统、全部物理输入/DPI 组合及长期稳定性未在此次重新验收；实际隔离验证与完整回归以本 Tag 对应记录为准。不要关闭系统防护。
